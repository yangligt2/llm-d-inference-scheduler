# Claims map

Every claim the paper makes, one row each. Row IDs (C01-C35) are the
paper's internal claim references; outline.md assigns rows to
sections. Result numbers refer to research-status.md (canonical).
Strength classes:

    demonstrated          direct measurement, replicated or
                          internally cross-checked; text may state
                          the fact without probabilistic hedging
                          (n still reported)
    probabilistic (n)     an outcome frequency over n draws; text
                          must state the tally, never a smoothed
                          probability
    model-supported       holds in the calibrated fluid/DES models;
                          text must attribute to the model and state
                          the validation scope
    open                  documented failure or unresolved question;
                          text reports it as such

SINGLE-DRAW rows are flagged in the last column with the mandatory
hedge form. Global hedging rule: any single-draw point is written as
"in the one measured draw" (or "one matched pair"), with n=1 inline,
and is never the sole support for a probability, threshold, or
monotonicity statement.
